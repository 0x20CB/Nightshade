# RFC#1: ALMAC

## Description

The Almac acts as an account ledger manager for the decentralized web by using block lattices and blockchain technology.

## Cryptography

Cryptography is implemented using the libslug library.

### Accepted Digital Signature Algorithms

#### Standardized

- [ ] ShulginSigning (ED25519 + SPHINCS+(SHAKE256))
    - [ ] Small Public Key and Private Key Sizes
- [ ] EsphandSigning (ED25519 + FALCON1024)
- [ ] AbsolveSigning (ED25519 + ML-DSA3)

#### Post-Quantum

- [ ] FALCON1024
- [ ] ML-DSA3
- [ ] SPHINCS+ (SHAKE256)

#### Classical

- [ ] ED25519
- [ ] ED448
- [ ] Secp256k1
- [ ] Schnorr
- [ ] BLS

---

### Accepted Hash Functions

- [ ] SHA256, SHA384, SHA512
- [ ] SHA3-256, SHA3-384, SHA3-512
- [ ] BLAKE2 (BLAKE2S + BLAKE2B)
- [ ] BLAKE3
